阅读约定与当前阶段定性

当前是开发者预览版（Developer Preview）、CLI 优先阶段。 核心闭环已在真实 Git 仓库端到端跑通，但面向普通用户的桌面应用尚未实现——目前只有无界面 CLI + 本地回环的四区 Web 工作台（供审阅与人工介入），Tauri 原生桌面外壳是下一步计划。
模型接入现状：当前仅支持 OpenAI Chat Completions 兼容（POST {baseUrl}/chat/completions）的文本补全，不依赖厂商 SDK；原生 Responses API、原生 tool-calling、Anthropic / Gemini 原生协议均为计划方向，不是现状。

诚信红线：不把 P1/P2 描述为「现在就能用」；Tauri 桌面外壳、Git 写操作、Windows 端到端、工作区扫描性能等缺口均如实标注。

0 · 一页纸摘要

  • 现在：证据原生、本地优先的工程 Harness；任务只有在每条必需条件都拿到规定等级有效证据时才进入 proven，模型口头说「完成」不算数。
  • 下一代：把已稳定的最小可信内核从「只服务软件工程」解放为「任意领域智能体都能挂载的通用基础」——内核负责状态权威/租约/证据/预算，模型、工具、验证器、Skill、客户端全部变成受治理可替换扩展。
  • 不变：内核唯一写权威、事件溯源可重放、每副作用要短时效租约、长期经验过防火墙、自治只在用户硬边界内增减。
  • 更强模型来了：只换 L2/L3 认知扩展包与模型适配器，不动内核一行。

1 · 定位

一句话：Keystone 是本地优先、证据原生的智能体基础——持续理解目标系统，在用户硬边界内完成复杂任务，并用可重放、可审计的证据（而非模型自述）证明结果可交付。

Keystone 的差异不在功能清单（统一运行时、多客户端、Skills/插件/Hooks、权限沙箱、会话分支、worktree、子 Agent 等已是主流共识基线，见仓库竞品分析），而在把 Contract / Lease / Proof 语义用一张可分叉运行图贯穿任务、工作区、证据与经验。这组语义与「软件工程」解耦：换一套领域验证器与能力出口，同一内核即可服务新领域。

人群痛点价值
资深工程师 / TL模型说完成却跑不通；崩溃不可恢复；换模型不可复现完成=证据图确定性查询；账本可重放；断点续跑；换模型语义不变
平台 / 内部工具团队每接一个 Agent 都要重做安全/权限/审计直接挂载内核：租约、预算硬停、人审、重放开箱即用
隐私/合规敏感用户代码与数据不能出本机本地优先 + BYOK；可选纯本地模型
扩展/生态贡献者改能力要碰核心、怕改坏安全模型受治理扩展 SDK：清单+完整性+一致性套件，隔离沙箱

2 · 非目标（明确不做）

领域范围更正：不把「个人 / 研究 / 创作 / 企业 / 设备·机器人」列为永久非目标。今天只交付软件工程垂直；其余场景是挂在同一套内核原语上的未来能力包。下列红线约束的是「做事方式与可信度」，不是「永不碰某类人群」。
  1. 不做以「Agent 数量」为目标、默认开启的多 Agent 软件工厂（子 Agent 须收益可证且隔离）；
  2. 不做中心化企业 Web 后台；不做移动端与远程签名；
  3. 不做自动付款 / 自动发邮件 / 自动生产部署；
  4. 不做无隔离、无一致性测试、无权限声明的插件/Skill 市场；
  5. 不把单次失败自动升级为长期项目规则；
  6. 不允许扩展替换状态机 / 权限签发 / 证据完整性 / 完成判定；
  7. 不把模型思维链当证明、审计记录或交付物（CoT 是数据，不是命令）。

3 · 稳定核心抽象（永不轻易破坏）

抽象职责不可逾越的规则
事件账本 Event Ledger追加不可变、哈希链、唯一事实源内核唯一写入者；扩展只能提交意图/观测
状态机 State Machine合法任务状态迁移迁移表受控；模型文本不能触发跃迁
结果契约 Outcome Contract目标/范围/完成条件/证据等级/预算/自治边界可版本化；换模型不改契约与完成口径
能力租约 Capability Lease每副作用要短时效、可撤销租约越界写即暂停可拒；扩展不能自授权
运行图 Run Graph检查点/分支派生/分支比较/恢复分支连接工作区+证据+经验，非复制聊天
溯源 Provenance来源/信任级/派生/失效条件上下文/记忆/证据都带来源与失效规则
证据 Evidence（E0–E4）分级证据与独立性判定E0 模型自述不能单独满足完成条件
证明图 Proof Graph完成判定=对证据依赖图的确定性查询全条件达标+未失效+未越界+链路完整才 proven
经验防火墙 Experience Firewall候选经验隔离→晋升/降级评估正迁移/负迁移/遗忘，可撤销
自治包线 Autonomy Envelope用户设定的最大硬边界模型/插件/历史成功不能自动扩大

双环：Builder Loop（理解/规划/编辑/执行）＋ Assurance Loop（结果/上下文/能力/验证/完成/学习/自治），同写一张运行图。

四模式：minimal（仅确定性检查，不调模型）/ standard / isolated（独立 worktree）/ replay。降级必须显式声明能力与证据等级损失，禁止静默降级后仍宣称同等证明强度。

4 · 双轨：普通用户 vs 开发者

普通用户轨 未实现成品

现状 本地回环 Run Protocol + 四区 Web 工作台单页（任务列表/目标与完成条件/证明与证据/人工介入），已在真实浏览器验证；仅监听回环、bearer token 走 URL fragment。

P1 Tauri 薄封装（原生窗口/菜单/托盘/深链/签名公证）。当前 Tauri 打包与原生集成尚未实现。

开发者轨 当前主力

现状 无界面 CLI（onboard/run/replay/proof export/protocol export）；BYOK=OpenAI Chat Completions 兼容文本补全；密钥 stdin 读入仅属主可读；离线 scripted 模型零 token；扩展 SDK + 参考扩展。

P1 ACP IDE 集成、非交互 CI、多项目管理、隔离并行写、协议适配器 SDK、MCP/Skills 集成。

普通用户目标体验（均为规划，未实现）：零配置启动；渐进式披露（默认只给目标→在做→完成三层）；落盘前 diff 预览；人可读完成回执（凭什么算完成/跑了哪些验证/token 花费）；异常优先决策（仅越界/高爆半径/超阈值时打断）；任意任务可撤销、可重放、可从检查点派生分支对比。
能力边界：当前没有原生 Responses 适配、厂商原生 tool-calling 集成、Anthropic/Gemini 原生 SDK 协议——均为互操作方向，非现状。

6 · 更强模型就绪性

已具备：统一 complete() 模型适配器；内核无 LLM、不联网；Builder/Assurance 可路由不同模型。当前适配器族为 OpenAI Chat Completions 兼容文本补全——更强模型只要讲这套协议即可接入，无需改内核。

级名称作用成本
L0反射 Reflex模式匹配/缓存决策，零 LLM毫秒级
L1校验 Verify小模型提案+证据核对低
L2推演 Deliberate强模型规划/多步工具中
L3关键 Critical多候选+自洽+人审+回滚补偿高
未来更强/更贵模型只替换 L2/L3 认知扩展包与模型适配器，内核零改动——成本与质量结构性解耦。

7 · 非功能需求（NFR）

成本 / 延迟 / 隐私 / 安全

  • 成本：token/时间/副作用预算由内核硬停，非模型自律；P1 引入候选漏斗与配额可视化。
  • 延迟（有数据，M3 Pro / Node22 / 20任务约85事件）：cli.cold-start p95 173.9ms；cli.task-list p95 166.1ms；kernel.task-switch p95 1.6ms（达标≤300ms）；proof.open p95 1.2ms。风险在工作区扫描（未测）与模型往返，NFR-PERF-01 严格未验证。
  • 隐私：运行时数据在被管仓库外（~/.keystone）；凭据仅属主可读；回环监听+fragment token；可选纯本地模型。
  • 安全：副作用必经租约；越界写暂停；外部内容=数据≠命令；高爆炸半径强制人审；POSIX 命令执行不经 shell；扩展违规即隔离并保留检查点。

可观测 / 重放 / 兼容

  • 可观测：执行轨迹、证据级联、证明图、降级记录均可查。
  • 重放：追加不可变账本+哈希链；同图重放得一致权威状态（NFR-REL-05）；证明包内容寻址、跨语言字节一致。
  • 兼容：依赖单向 cli→runtime→{kernel,tools,verifiers,models,extensions}→schemas；内核零运行时依赖；macOS 真机验证，Windows 仅预览态（未跑端到端）；Git 写操作（commit/rollback）未实现。
换模型的准确含义：NFR-REL-04 保证切换模型不改变业务状态、契约、完成判定口径与证据规则；不承诺不同模型产出相同代码或相同中间路径——后者由可复现评测量度，不由内核掩盖。

9 · 成功度量（不靠功能数量）

稳定版须在「同模型/同任务/同权限/同时长/同 token 预算」下跨阶段达标：

  1. 在验证完成率 / 人审率 / 上下文成本至少一个维度显著优于当前最佳可复现基线；
  2. 逃逸缺陷率、越界变更率、生命周期安全指标不退化；
  3. 恢复/重放/分支合并均有确定性证据；
  4. 开启长期经验后正迁移可观测，负迁移与遗忘不超发布闸门；
  5. 新插件/模型/协议/策略不破坏 Contract/Lease/Provenance/Evidence/Proof 不变量。
具体阈值由公开基线评测产生，无数据不预设；「领先」须引用 scorecard 与可复现实验。Standard 与 Minimal 双档运行以分离「模型能力」与「Harness 增益」。

11 · 已验证趋势 vs 标注预测

已验证（官方/高置信来源）

  • 「主流工程 Agent 功能共识」是 Keystone 自家竞品分析文档的立场，本文不将其当作独立第三方量化事实。
  • MCP 由 Anthropic 2024-11 开源；Agent Skills 由 Anthropic 发布并于 2025-12-18 开放为跨平台标准；A2A 由 Google 发起并捐赠 Linux Foundation；ACP 为编辑器与 Agent 间 stdio 协议；Local-first 与 Event Sourcing 为成熟范式。

明确标注的预测（FORECAST，需实测验证）

  • 预测：强模型仍显著贵于小模型，「廉价候选漏斗」会成主流成本结构。
  • 预测：Agent 协议继续分段演进，「在恰当边界挂标准、内核语义自守」比自研大一统更可持续。
  • 预测：模型越强，外部硬约束层（租约/预算/证据完成）价值越升而非下降。
  • 预测：本地优先+BYOK+可重放审计在合规/隐私场景成为刚需差异。
